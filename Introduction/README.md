# ESP32 Speed Detection System

An ESP32-based real-time speed detection system using dual HC-SR04 ultrasonic sensors.

## Features

- Real-time speed calculation
- Dual ultrasonic sensor measurement
- LCD1602 display
- Configurable speed limit
- Overspeed buzzer alarm
- Invalid data filtering
- Automatic system reset

## Hardware

- ESP32 DevKit V1
- HC-SR04 ×2
- LCD1602A
- Active Buzzer

## Development Environment

- Arduino IDE
- ESP32 Arduino Framework
- Wokwi Simulator
